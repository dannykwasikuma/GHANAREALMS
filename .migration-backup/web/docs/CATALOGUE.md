# GhanaRealms catalogue, pricing and admin

## What exists (all in this repo)
- **375 products** generated by `web/scripts/generate_catalogue.py` into `web/migrations/009_catalogue.sql` (armour, weapons, tools, elytra/rare, every enchantment book at every level, Ghanaian food, potions, bundles, cosmetics). Edit the script, regenerate, or edit live in `/admin/products`. Re-running the migration never overwrites admin edits.
- The generator **refuses to emit** any enchantment that is inapplicable to the item, above vanilla max level, or mutually exclusive with another on the same item (e.g. Protection + Blast Protection, Mending + Infinity). Curses are not sold.
- **Two separate price systems**: `price_pesewas` (GH₵, web) and `ingame_price_minor` (coins, Vault). Either can be blank = not sold that way. **No exchange rate is assumed anywhere.**
- Stock (shared web + in-game), per-player limits (lifetime or rolling N days), percentage discounts with end dates, seasonal availability windows, gameplay-only items.
- Website: `/store` (GH₵ items), `/store/<slug>`, `/catalogue` (everything, both prices), admin `/admin/products`.
- Minecraft: `GhanaRealmsItems` plugin - `/gritem give` (builds named/enchanted/potion items through the Bukkit API, version-proof; used by web delivery) and `/gshop` (GUI, synced from `/api/bridge/catalogue` every 5 min, reserves stock/limits on the store before charging coins, refunds the reservation on failure).

## Fairness rules built in
- Real money only buys cosmetics (Adinkra chat titles), Ghanaian food baskets and Beginner/Diamond/Nether explorer bundles (limited 1-2 per player, per 30 days for the bigger ones). Netherite, elytra, totems, nether stars, treasure enchants, mace, exclusive weapons: coins only, with weekly/biweekly per-player limits; Nether Stars, Wither Skulls, Dragon Heads and the exclusive Ghana weapon collection also have limited stock. Dragon Egg and Beacon are gameplay-only.
- Enchanted gear price = base + 80% of its books' prices; books price = base x level^1.7 (treasure enchants much higher). Beginners: leather set 300, iron set 800, a full Jollof portion 15 coins.

## Setup / testing steps (nothing below was run on a live server)
1. `psql -f migrations/00N_*.sql` in order. (Verified: all of 001-009 apply cleanly to PostgreSQL 16, constraints and stock/limit SQL exercised by hand.)
2. Build and install `GhanaRealmsItems` (needs Vault + an economy plugin). Set BRIDGE in its config. Confirm the Paystack plugin's delivery runs `delivery_commands` as console - the catalogue relies on `gritem give {player} ...`.
3. Check PotionType names / enchantment keys on your exact server build (`/gritem give <you> POTION 1 potion=STRONG_HEALING`). Items that fail to build are refused before any charge.
4. Do a Paystack test-mode purchase of "Ghanaian Food Basket" end to end.

## Marketplace map (GhanaRealmsMarket plugin)
I cannot see or edit your world files, so the marketplace is built **by a plugin, in-game, on your map**:
1. Install `GhanaRealmsItems` (shop) and `GhanaRealmsMarket`. Stand at the centre of a FLAT area (or a test world) and run `/gmarket plan` - it prints the exact 163x163 footprint, which it will clear and replace (back up the world first).
2. `/gmarket build confirm` builds, tick-limited so the server does not freeze (BLOCKS-PER-TICK in config).
3. Layout (3x3 grid, 7-block laterite roads with lamp posts): Okaishie Electronics & Equipment, Kumasi Armour & Weapons, GhanaRealms Premium & Luxury, Kejetia Food & Grocery Market, **Main Marketplace plaza** (Black Star in gold, 3 Ghana flags, Independence arch, fountain), Tema Building Materials Market, Gold Coast Special Items & Trading Centre, **GhanaRealms Shopping Mall** (glass-fronted, 10 shop fronts), Player-Owned Business District (12 fenced rentable plots; use GhanaRealmsShops sign shops there). Stalls have kente-striped roofs; every shop sign reads `[GShop]` + category and opens that category of the coin shop when right-clicked.
4. Also built (previously "not covered"):
   - **Terrain shaping**: the build samples the 163x163 footprint, cuts hills/trees/water above the floor and fills hollows/shallows/ravines (up to 48 blocks deep) with dirt, so it works on uneven land. It still replaces everything inside - back up first.
   - **Shopkeeper NPCs**: a frozen, invulnerable villager behind every stall and mall front (profession matches the category). Right-click opens that category of `/gshop`. `/gmarket removenpcs` removes them; rebuilding removes old ones first.
   - **Built-in protection** (no WorldGuard needed): the whole marketplace is protected from breaking/placing, buckets, TNT/creeper blasts, fire, flooding from outside, trampling, entity block changes, hanging-item breaking and natural monster spawns (raids/apocalypse still work). Region saved in `plugins/GhanaRealmsMarket/region.yml`. Ops have `ghanarealmsmarket.bypass`.
   - **Rentable plots**: `/gmarket plot list`, `/gmarket plot assign <n> <player>`, `/gmarket plot release <n>` - owners can build inside their 9x9 plot (above the floor); the plot sign updates with the owner's name.
   - **Fashion House** (mall): its sign/NPC shows the website store link for Adinkra chat titles (cosmetics are GH₵-only, bought on the site).
   Still not included: interior decoration beyond what is generated, custom skins for NPCs, hats/wings/pets/trails (need a resource pack and other plugins).
5. Untested in a live world: block placement, sign orientation and layout spacing were reasoned out, not seen. Run it first in a throwaway world and tell me what looks wrong.

## Shop systems: who sells what
- **/servershop (GhanaRealmsShops)**: walk-in chests for plain commodities (blocks, ores, farming, redstone...), buy AND sell back, fixed config prices. Building-materials stalls in the market open `/servershop open blocks`.
- **/gshop (GhanaRealmsItems)**: the synced catalogue (enchanted/named gear, kits, rare items, potions, food packs, bundles) with stock + per-player limits shared with the website.
- The duplicate "building materials" category was removed from the catalogue so no block has two prices.
- Commands renamed to avoid a clash: GhanaRealmsLinkPlugin's `/store` is now `/myaccount` (UltimateDonutSMP already owns `/store`).
